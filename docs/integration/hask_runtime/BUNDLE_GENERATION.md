# HASK consumer bundle generation

The packaged HASK consumer bundle is an immutable, versioned resource. Published
content under `src/hadocs/knowledge/hask_bundle/<version>/` is never regenerated
in place. A content change uses a new patch version and updates packaged discovery.

`scripts/build_hadocs_contract.py` is the official deterministic generator. Each
new version has a declarative source patch under `scripts/hask_bundle_sources/`.
The generator reads the immutable base bundle, applies additions and replacements
in memory, validates typed artifact envelopes, stable identities, duplicate IDs,
references, relationships, provenance, and the runtime contract, then writes
sorted canonical UTF-8 JSON only when bytes differ.

For every artifact it calculates SHA-256 over the exact generated bytes. The
aggregate checksum frames each sorted artifact filename and its bytes with NUL
separators, matching the runtime loader. The generator also deterministically
updates manifest counts, per-artifact hashes, and the aggregate checksum. Values
that describe the unchanged upstream authoritative dataset and schema registry
remain inherited from the immutable base manifest.

Build and validate the current bundle:

```powershell
py -3.14 scripts/build_hadocs_contract.py --version 0.2.1
py -3.14 scripts/build_hadocs_contract.py --version 0.2.1 --check
```

The second command fails when generated files are stale and succeeds without
writing when the bundle is reproducible.
